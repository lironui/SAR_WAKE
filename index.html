SAR-WAKE

A SAR-based offshore wind-farm wake detection framework

SAR-WAKE is an open-source research code package for detecting offshore wind-farm wake effects using Sentinel-1 SAR imagery.

Overview

This project provides a reproducible workflow for offshore wind-farm wake detection, including upstream/reference area identification, wake-affected area detection, and wind-direction-guided region growing.

Features

  • Sentinel-1 SAR image processing
  • Wind-direction-guided wake detection
  • Region-growing based wake segmentation
  • Research-ready reproducible workflow

Installation

git clone https://github.com/lironui/SAR_WAKE.git
cd SAR_WAKE
pip install -r requirements.txt
